Joined a 5-person R&D team building enterprise blockchain products. The team shifted focus to self-sovereign identity and grew past 40 people on the technical foundations I designed:

- Designed and led most of the foundations for Atala PRISM (now Hyperledger Identus, https://identus.io), a self-sovereign identity (SSI) ecosystem built around Decentralized Identifiers (DIDs) and Verifiable Credentials.
- Designed the initial second layer protocol for storing decentralized identifiers and digital credentials on top of Bitcoin, and the initial architecture for the Credentials Verification project.
- Designed and implemented the first PRISM SDK, cross-platform so web, mobile and backend clients shared a single implementation.
- Built the API documentation website so that every code snippet was compiled as part of the build, which meant the examples could never drift from the SDK.
- Coordinated external vendors delivering our initial mobile and web apps, and wrote technical design proposals for prospective customers.
- Presented PRISM at public events, on-site in Mexico (Viva La Crypto, Talent Land) and online: https://www.youtube.com/watch?v=8AbgzvOeb6w
