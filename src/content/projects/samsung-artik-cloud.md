Worked on ARTIK Cloud (now SmartThings Enterprise), an IoT platform to connect devices and applications. Implemented S3 resiliency across regions for the image storage service, so a regional S3 outage no longer takes the service down. Implemented TCP and TLS support for the LwM2M protocol used for IoT device management, and backported fixes into upstream Eclipse Leshan and Californium. Contributed to a multiple-active-regions project using multi-master asynchronous database replication across regions worldwide, using Conflict-Free Replicated Data Types (CRDTs), and to the Device Management Approved List, which lets an organization whitelist the devices allowed to connect to the cloud.
